# Roadmap

## Sprint 1 — Foundation

- Project setup
- Documentation
- Cursor Rule
- Initial commit
- Push to GitHub

---

## Sprint 2 — Repository Inventory

- Review all repositories
- Categorize each repository
- Decide:
  - ⭐ Showcase
  - ✅ Keep
  - 📦 Archive
  - 🔒 Private
  - 🗑 Delete
  - 🍴 Fork Cleanup

---

## Sprint 3 — Repository Improvement

Improve repositories that matter:

- README
- Description
- Topics
- Screenshots
- Documentation

---

## Sprint 4 — GitHub Profile

- Profile README
- Pin repositories
- Repository descriptions
- Final review

---

## Completion

GitHub Recovery is complete when:

- The GitHub profile looks professional.
- Showcase repositories are polished.
- Unnecessary repositories have been handled.
- The profile supports job applications.
