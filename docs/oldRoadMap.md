# Roadmap

## Phase 1 — Repository Inventory ✅ (Completed)

- Repository list
- Public / Private status
- Fork vs original
- Languages
- Missing descriptions
- Private repositories
- Fork list

## Phase 2 — Classification

Every repository gets one status:

| Status | Meaning |
|--------|---------|
| ⭐ Showcase | Portfolio-quality; polish and promote |
| ✅ Keep | Active or useful; maintain as-is |
| 📦 Archive | Historical; archive on GitHub |
| 🔒 Private | Not for public display |
| 🗑 Delete | Safe to remove |
| 🍴 Fork Cleanup | Fork to keep, unfork, or delete |

## Phase 3 — Planning

```
Issue → Sub-issues → Tasks → Commit
```

Everything becomes trackable through GitHub Issues and Projects.
