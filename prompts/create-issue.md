# Create GitHub Recovery Issue

When creating a new issue for this repository, always follow these rules:

## Project Management

- Assign the issue to @Lakhwinderr.
- Add the issue to the "GitHub Recovery" project.
- Select the correct sprint milestone.
- Apply appropriate labels.

## Issue Structure

Every issue should include:

- Objective
- Deliverables
- Definition of Done

Use checklists whenever appropriate.

## Workflow

Do not create unnecessary issues.

Maintain a small backlog:

- One issue In Progress.
- Two to four issues in To Do.

Keep issues focused, actionable, and directly related to the current sprint.
